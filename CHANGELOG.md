# Changelog

## Unreleased — 0.3.0 public preview preparation

- Phone browser trackpad, scrolling/momentum, native pinch, keyboard controls, and appearance settings for a Linux receiver.
- Browser pairing page with private QR/link, live connection status, gesture help, and authenticated shutdown; desktop launcher.
- A Makefile for building, installing/removing, input setup, diagnostics, tests, and release archives.
- User installation/update/removal guides, security model, contribution guide, and maintainer release checklist.
- Private-address binding, ordinary-user input execution, stricter saved-key handling, atomic key rotation, and a service option that suppresses pairing output.
- Explicitly packaged Linux release archives with checksums, a draft release workflow, and expanded CI checks.

Known limits: Linux only; trusted Wi-Fi or manually configured trusted HTTPS; shared bearer pairing without individual revocation; US-layout ASCII typing; native pinch/compositor and physical-phone validation required. No general availability, latency, or battery guarantees.
